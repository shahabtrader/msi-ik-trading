# 📊 ShahabPrime MSI IK Trading Dashboard

A **real-time market microstructure dashboard** for cryptocurrency trading with live Binance data integration.

## 🚀 Features

- **📖 Order Book & Spoofing Radar** - Real-time order book imbalance
- **🌡️ VPIN Meter** - Volume-Synchronized Probability of Informed Trading
- **💰 Smart Money (CVD)** - Cumulative Volume Delta tracking
- **🎯 Kelly Criterion** - Position sizing calculator
- **🪙 Multi-Coin Comparison** - Track multiple coins simultaneously
- **📈 Historical Backtest** - Order-flow vs returns analysis
- **💸 Funding & Volatility** - Real-time funding rates
- **📐 Risk Metrics** - Sharpe, Sortino, Max Drawdown, Monte Carlo
